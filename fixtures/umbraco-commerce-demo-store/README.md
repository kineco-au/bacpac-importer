# Umbraco Commerce Demo Store

`UmbracoCommerceDemoStore_v17.0.0.bacpac` is the demo database from
[umbraco/Umbraco.Commerce.DemoStore](https://github.com/umbraco/Umbraco.Commerce.DemoStore)
(`db/`, at commit `771f569`), copied unmodified. It is MIT licensed; see
`LICENSE.md` beside it.

An Umbraco 17 site with Umbraco Commerce, exported from SQL Server 2019: 127
tables, 10,305 rows. It is demonstration data and holds nothing personal, which is
why it can be committed when real exports cannot.
